Drone Ranger hardware stack

The Spring 2026 prototype, plus what the hardware group rebuilds and adds this semester so it can fly an approved autonomous patrol over a household garden. The whole platform is about $1.5k of open parts.

How the parts connect

Wire labels are Pixhawk 6C connectors and the protocols that run over them.

  • Added or rebuilt this semester (parts and wiring)
  • New setting or software in a carried-over part
  • Only if funded
  • Algorithm group, outside this charter

Layer by layer

Each layer depends on the ones below it. The right column is the charter metric that shows the layer works.

  1. Operating envelope

    Rules every outdoor flight runs inside.

    Daylight · visual line of sight · low altitude · geofence inside the property line · NU UAS Review Board approval · FAA Part 107 pilot and Remote ID · written homeowner permission · CA Civil Code §1708.8 privacy

    GateApproved before the first outdoor flight

  2. Missions

    What the drone flies this semester.

    • O1 · manual / Position mode
    • O2 · PX4 Mission-mode patrol
    • QGroundControl mission planning

    Target≥ 1 garden loop (≥ 4 waypoints + return) with no pilot takeover

  3. Safety

    Stops the drone or brings it home when something fails.

    • RC kill switch
    • Geofence inside the lot line
    • Return to launch
    • Battery failsafe
    • Link-loss failsafe

    Target100% of failsafes verified

  4. State estimation

    Where the drone thinks it is.

    • EKF2 sensor-fusion setup
    • IMU + barometer
    • GNSS + compass on a mast
    • TFmini Plus rangefinder
    • RTK GNSS H-RTK F9P

    TargetHover altitude RMSE ≤ 0.15 m (Spring: up to 0.5 m). Waypoint error measured against surveyed markers, ≤ 0.3 m with RTK.

  5. Flight control and links

    Flies the aircraft and talks to the ground and the Jetson.

    • Pixhawk 6C
    • PX4 Autopilot
    • Fixed port map TELEM1 radio · TELEM2 XRCE · TELEM3 TFmini
    • FTDI serial link 921600 baud
    • Versioned parameter file
    • SiK radio ↔ QGroundControl

    Target0 link drops

  6. Companion and perception

    Onboard computer and depth camera, handed to the algorithm group.

    • Jetson Orin Nano 8 GB
    • Ubuntu 22.04 · ROS 2 Humble
    • Micro XRCE-DDS Agent
    • OAK-D Lite + depthai-ros
    • Documented depth + TF interface
    • One-command launch

    TargetInterface documented and handed over

  7. Airframe and power

    What everything is mounted on and powered from.

    • Holybro X500 V2
    • 4S LiPo
    • Fused, insulated power distribution
    • Protected 12 V BEC for the Jetson
    • Wiring diagram + bill of materials

    Target0 electrical incidents · ≥ 10 min usable flight

  8. Off the aircraft

  9. Test toolchain

    Rehearse before each flight, analyze after.

    • PX4 SITL + Gazebo gz_x500_depth
    • ULog → Flight Review + analysis scripts
    • Pre-flight checklists

    TargetEvery mission passes in SITL before it flies

Not in this stack (charter, Outside of scope): obstacle avoidance, mapping and path planning (algorithm group) · ROS 2 offboard control outdoors · RL / Isaac Sim · custom flight-controller firmware · multi-drone operation · docking and charging · payloads.
